# 双人默契大乱斗 · LINK / ARENA

一台电脑、两位玩家的本地同屏竞技游戏。三种模式均可在主菜单选择，所有资源均在本地，无需联网、登录或安装游戏依赖。

## 开始游玩

**最快：用 Windows Edge 或 Chrome 打开 `双人默契大乱斗-双击即玩.html`。** 这是完整的单文件版本，可独立复制给另一台电脑。

手柄推荐使用本机网页服务：在当前目录双击 `开始游戏.cmd`，保持命令窗口开启，在浏览器打开 **http://127.0.0.1:4178**。需要电脑已有 Node.js。本次制作环境已安装。也可在此目录运行 `npm start`。

服务只监听 127.0.0.1，仅用于本机游玩。退出服务按 Ctrl+C。多文件入口 `index.html` 与单文件版内容相同。

## 键盘与手柄

| 动作 | 玩家一 | 玩家二 | Xbox / 标准手柄 |
| --- | --- | --- | --- |
| 移动 | W 上、A 左、D 右、Z 下 | 方向键 | 左摇杆 / 方向键 |
| 普通攻击 | 1 | 7 | A |
| 冲刺 | 2 | 8 | B |
| 技能 | 3 | 9 | X |
| 格挡 / 共振 / 救援 / 特殊能力 | 4 | 0 | Y |
| 暂停、继续 | Esc | Esc | 菜单键 ☰ / Start |

玩家一（爸爸）可用 W/A/D/Z 移动，玩家二（你）用方向键移动。玩家二可使用键盘上排数字或小键盘数字，0 键对应模式动作；小键盘建议开启 Num Lock。普通攻击可按住连打；冲刺、技能和特殊能力须松开后重新按。命中近战会累积连击，连续四击触发重型终结技；造成伤害会积攒必杀能量，蓄满后技能键释放五发扇形爆发。HUD 会显示能量条、连击与技能冷却。停止移动时自动朝向敌方；近战也可用移动方向调整朝向。怪兽会优先瞄准附近设施。

Windows Xbox 手柄使用浏览器 Gamepad API 的 standard 映射。先用 USB 或 Windows 蓝牙连接两只手柄，在游戏页面按一次任意手柄键。主菜单会显示识别状态，可分别为 P1、P2 选择指定手柄、自动分配或仅键盘。两位玩家不能占用同一只指定手柄。可用一只手柄配一套键盘，也可完全使用双人键盘。

手柄可操作菜单：方向键 / 摇杆移动焦点，A 确认，B 返回。在设备下拉框上按 A 可轮换设备。断线后比赛自动暂停，接回后按任意键重新识别；原玩家的键盘始终可以接管。切出页面也会暂停。通用手柄若非 standard 映射，建议改用 Windows Xbox 兼容模式。

## 三种模式

**擂台对决：** 三局两胜，每回合 75 秒。击倒对手获胜，超时按剩余生命判定，平局加赛。协作键可按住格挡，减伤 70%，消耗能量并减速。冲刺短暂无敌；能量松开后恢复。

**双星共振：** 两人在 150 秒内击败三阶段巨兽。先分别进入左右装置范围，同时按住协作键 1.3 秒，将巨兽护盾解除 11 秒。护盾期间只能造成 16% 伤害。破盾后两人在 0.65 秒内释放技能，可追加 50 伤害并略延长输出窗口。躲避红圈和弹幕；搭档倒地后，靠近并按住协作键 1.6 秒可救起。两人同时倒地或超时则失败。

**巨兽警报：** 默认 P1 怪兽、P2 英雄，可在战前或结算交换角色。怪兽 440 生命，目标是拆毁三座设施或击倒英雄；具备重爪、伤害冲撞、投石和范围咆哮。英雄 180 生命，目标是击败怪兽，或存活并保住至少一座设施 120 秒；具备近战、闪避、能量弹与高能光束。咆哮冷却 7 秒，光束冷却 8 秒，光束有效范围 700。

每种模式均有游戏内规则、倒计时、胜负结算、重新开局与返回菜单。音效默认关闭，可在顶部开启；音效由本地 Web Audio 生成。
